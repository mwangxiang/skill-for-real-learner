# Pilot-native sidebar evidence

This directory preserves both the rejected and admitted runtime candidates.

- `alpha19-pilot-dock-open.png`: first native-dock render. It proved the panel
  was no longer a fixed overlay, but the candidate was later rejected because
  Files and Work Space could render together in one 320 px track.
- `alpha21-pilot-dock-open.png`: admitted P3 candidate. Native conversation and
  composer remain visible; Work Space occupies the Pilot right-sidebar track;
  Files is closed and the details column has yielded.
- `alpha21-runtime-evidence.json`: identities, hashes, commands, geometry,
  conflict probes, failures, and scope boundaries.

The screenshots contain only an isolated smoke workspace and a keyless replay
response. They contain no credentials or user project data.
