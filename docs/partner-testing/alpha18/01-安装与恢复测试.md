# 01｜安装、启动、恢复和卸载

## 一、前置条件

- Windows；Node.js `22.19+` 或 `24+`。
- 官方 DeepSeek Harness `0.1.1-rc.2`。
- DSH 原生模型凭据已经可用。
- 一个独立空目录作为测试工作区。
- 本包中的：

  `plugin/mwangxiang-dsh-visual-learner-0.1.0-alpha.18.tgz`

不要把 API Key 写入命令、Markdown 或反馈表。

## 二、建议的隔离目录

```powershell
$trialDshHome = 'D:\DSH-Partner-Trial\dsh-home'
$trialWorkspace = 'D:\DSH-Partner-Trial\workspace'
New-Item -ItemType Directory -Force -Path $trialDshHome, $trialWorkspace
$env:DSH_HOME = $trialDshHome
```

请把路径替换成你自己的绝对路径。每次新开 PowerShell 后都要重新设置 `$env:DSH_HOME`。

## 三、校验插件包

在测试包根目录运行：

```powershell
Get-FileHash -Algorithm SHA256 '.\plugin\mwangxiang-dsh-visual-learner-0.1.0-alpha.18.tgz'
```

预期：

```text
7FCDBF8609C1481A28066F5EE25002CE4289742D531616BA02DCDD6276DA1193
```

不一致就停止安装，重新取得测试包。

## 四、安装插件

如果系统里已有 `dsh` 命令：

```powershell
$env:DSH_HOME = $trialDshHome
dsh plugin --profile web add (Resolve-Path '.\plugin\mwangxiang-dsh-visual-learner-0.1.0-alpha.18.tgz')
```

如果使用官方源码仓库，在官方仓库根目录运行：

```powershell
$env:DSH_HOME = $trialDshHome
pnpm dsh plugin --profile web add '测试包中 tgz 的绝对路径'
```

安装成功后，`$trialDshHome\profiles\web\package.json` 应包含：

```text
@mwangxiang/dsh-visual-learner
```

## 五、启动 Web Profile

有全局 `dsh` 命令：

```powershell
$env:DSH_HOME = $trialDshHome
dsh web --no-open --port 3080
```

使用官方源码：

```powershell
$env:DSH_HOME = $trialDshHome
pnpm dsh --profile web --no-open --port 3080
```

用浏览器打开：

```text
http://127.0.0.1:3080/
```

在原生 Harness 中选择 `$trialWorkspace`，新建或选择一个会话。会话标题区域应出现“打开工作空间”按钮。

## 六、重启恢复

1. 完成至少一个 PPT v1。
2. 在启动 DSH 的 PowerShell 窗口按 `Ctrl+C`，确认退出。
3. 用第五节同一条命令重新启动。
4. 刷新浏览器，等待 3–5 秒后打开插件。
5. 项目、当前版本、历史版本和状态都应恢复。

如果服务刚启动就立刻打开插件，偶尔会先看到空首页；这是已知连接时序问题。刷新并等待 3–5 秒后应恢复，请记录是否出现。

## 七、卸载与恢复

停止 DSH 后执行：

```powershell
$env:DSH_HOME = $trialDshHome
dsh plugin --profile web remove @mwangxiang/dsh-visual-learner
```

使用官方源码时把命令开头换成 `pnpm dsh`。

卸载后检查：

- 原生 Harness 可以正常启动；
- 插件入口消失；
- 测试工作区中的 `work-projects/` 仍存在；
- PPTX、Markdown、`.dsh-work/` 和 `assets/` 没有被删除。

然后重新安装同一个 tgz 并启动。原项目应重新出现。
