# DSH Work & Learning 合作伙伴测试包

> 版本：`0.1.0-alpha.18`
>
> 兼容范围：仅承诺官方 DeepSeek Harness `0.1.1-rc.2` Web Profile
>
> 性质：合作伙伴私测，不是公开发行版

## 这次测试的是什么

这个插件的本职不是“先教你学习”，而是：

1. 先帮助你完成一项真实工作，生成可使用的成品；
2. 从需求、初稿、修改和终稿中自动沉淀偏好与检查清单；
3. 工作完成后，再提供完全可选的学习建议。

当前版本只做通一个黄金场景：**生成、修改并确认一份约 7 页的工作汇报 PPT**。

普通用户看到的流程只有三步：

```text
告诉我想做什么 → 看 AI 做出的初稿 → 修改或确认
```

## 测试包内容

- `plugin/`：可直接安装的预构建 `.tgz`。
- `01-安装与恢复测试.md`：安装、启动、重启、卸载和恢复命令。
- `02-重点测试清单.md`：按顺序试跑的体验和功能检查。
- `03-反馈模板.md`：请直接填写后发回。
- `docs/`：产品 Spec v4 和本机真实闭环测试报告，供开发者追溯。
- `SHA256SUMS.txt`：插件包和整个测试 ZIP 的校验信息；ZIP 自身哈希另附在同目录文本中。

## 测试前须知

- 请使用独立 `DSH_HOME` 和独立测试工作区，避免污染日常环境。
- API Key 只在 DSH 原生凭据设置中配置，不要写进 Markdown、反馈表或截图。
- 插件不会默认扫描 Obsidian Vault、HOME 或其他磁盘。
- 卸载插件不应删除 `work-projects/`、PPTX、Markdown 和资产文件。
- 当前包内含尚未完成公开许可证处理的学习来源，因此只用于合作伙伴测试，不要公开上传、转发或发布到 npm。

## 最希望你回答的四个问题

1. 不看开发文档，你是否知道第一步该填什么？
2. 第一版 PPT 是可直接发送、只需微调，还是需要重做？
3. 你是否能在三轮修改内得到满意终稿？
4. “资产沉淀”和“可选学习”有没有帮助，还是干扰了工作？

请先读 `01-安装与恢复测试.md`，再按 `02-重点测试清单.md` 试跑。
